# Run the five demos

Start with **[Setup](learn/README.md)**, run its one command, then go directly
to **[Demo 1](learn/demo01.md)**. Every page includes the code to inspect and
the commands to run. No cloud setup is required.

| Demo | Learn |
| --- | --- |
| [1: baseline](learn/demo01.md) | Inspect the legacy C# project and ask for the migration |
| [2: author a skill](learn/demo02.md) | Turn team notes into reusable Copilot knowledge |
| [3: guided migration](learn/demo03.md) | Apply the skill and evaluate real behavior |
| [4: regression](learn/demo04.md) | Reproduce a broken contract, then fix the code |
| [5: reuse](learn/demo05.md) | Apply the same skill to batch serialization |

`v03/` contains shared prompts/checkpoint source still used by the current
setup. `captures/` contains placeholders marked not-run, not recorded runs.

Find more community skills at [Awesome Copilot](https://awesome-copilot.github.com/).
